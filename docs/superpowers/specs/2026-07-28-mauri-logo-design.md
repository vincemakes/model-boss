# Mauri Logo Design

## Goal

Create a minimal, original SVG mark for Mauri, an agent microkernel library. The mark must remain legible as a small developer-tool icon and must not imply a fixed number of agents.

## Core idea

The logo represents a minimal empty kernel surrounded by a continuous routing topology:

- A central negative space represents the deliberately small microkernel.
- A closed, endpoint-free outer form represents a routing layer that can accept any number of agents.
- Interweaving or controlled crossings represent delegation, handoff, and return.
- Geometric symmetry supplies visual order only; repeated elements must not be described as literal agent channels.

## Visual constraints

- True SVG geometry, not an embedded or traced raster image.
- Pure black on transparent or white background.
- Strict rotational or bilateral symmetry.
- No text, letters, monograms, mascots, gradients, shadows, textures, or 3D effects.
- No isolated ports, spokes, or petals that suggest a fixed capacity.
- Generous negative space and a silhouette that survives at 16 by 16 pixels.

## Candidate directions

Produce three count-agnostic closed forms:

1. **Continuous weave** — a compact, seamless knot with a clear central void.
2. **Orbit kernel** — a calmer closed orbital form with subtle routing overlap.
3. **Bounded flow** — a more architectural symmetric loop with stronger edges.

All candidates should share the same view box and optical scale so they can be compared fairly.

## Deliverables

- Three standalone editable SVG files.
- One browser comparison page showing the marks at large and favicon sizes.
- SVG validation and raster previews for visual inspection.
